## Flagship projects

### [synth-farm](https://github.com/bandalok/synth-farm)
Solve the cold start problem through synthetic personas: a farm of simulated users that search, click, and stream to generate behavioral training data for recommender systems.

### [pm-roadmap-agent](https://github.com/bandalok/pm-roadmap-agent)
Agentic AI system that turns raw product feedback into a living roadmap: theme clustering, trend tracking, RICE scoring, and a human-in-the-loop triage UI.
